02 — Aplicação web · planejamento financeiro

Marivan Finance

Aplicação web para controle e planejamento financeiro: despesas, categorias, rateios, comprovantes e indicadores.

01Identificação

Natureza
Projeto autoral
Atuação
Desenvolvimento da aplicação.

Estado de implantação não divulgado.
Acesso
Repositório privado. Não há link público e nenhum dado financeiro é exibido.
Stack
ASP.NET Core 10 · C# · Entity Framework Core · SQL Server · Windows Authentication · IIS · GitHub

02Contexto

ProblemaPlanejar o orçamento e acompanhar despesas exige categorizar gastos, dividir custos e guardar comprovantes. Essas tarefas costumam ficar espalhadas entre planilhas e arquivos.

AmbienteAplicação web hospedada em IIS, com identidade integrada ao Windows.

ObjetivoReunir planejamento, despesas, categorias, rateios, comprovantes e indicadores em uma única aplicação.

  • O repositório é privado.
  • Nenhuma informação financeira real é apresentada neste portfólio.

03Estratégia de solução

Aplicação em camadas sobre o ecossistema .NET: interface web, regras de negócio em C# e persistência com Entity Framework Core sobre SQL Server.

Decisões de engenharia e suas justificativas
DecisãoMotivo
Arquitetura em camadasMantém regras de planejamento e rateio fora da interface e do acesso a dados.
Entity Framework Core sobre SQL ServerModelo de dados versionável e consultas tipadas.
Windows AuthenticationA identidade vem do ambiente, sem gerenciar senhas na aplicação.
Versionamento e CI/CD no GitHubHistórico rastreável e entrega repetível da aplicação.

Áreas funcionais

06Demonstração

Não há demonstração pública: o repositório é privado e nenhum dado financeiro é exibido neste portfólio.

07Desafios

  • Rateios exatos

    Dividir um valor entre categorias ou pessoas exige uma regra explícita para arredondamento, de modo que as partes somem sempre o total.

  • Comprovantes

    Arquivos associados a registros financeiros pedem controle de acesso e de tamanho.

08Resultados e aprendizados

  • Demonstra desenvolvimento de ponta a ponta no ecossistema .NET, do banco à interface.
  • Não há métricas de uso divulgadas.

Regras financeiras pedem precisão: tipos decimais, testes de arredondamento e totais conferíveis.
