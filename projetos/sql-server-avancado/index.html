SQL Server em profundidade

Consultas analíticas, janelas, CTEs, índices e plano de execução em T-SQL, com exemplos didáticos em dados fictícios.

Escopo
Exemplos didáticos em tabelas fictícias. Não é administração de banco de dados.
Acesso
Sem nomes de servidores, bancos ou estruturas reais.

01Consulta analítica com janela

Funções de janela calculam acumulados e comparações entre linhas sem colapsar o resultado, o que evita junções repetidas.

03Índices e plano de execução

Um índice ajuda quando a consulta filtra e ordena pelas colunas da chave. Colunas de retorno entram em INCLUDE para evitar a leitura da tabela inteira.

Como investigar uma consulta lenta

  • Ler o plano de execução real e procurar leituras de tabela inteira (scan).
  • Conferir estimativas de linhas contra as reais: grande diferença indica estatísticas defasadas.
  • Evitar funções sobre a coluna filtrada, que impedem o uso do índice.
  • Medir com SET STATISTICS IO ON antes e depois de cada mudança.

04Views, procedures e jobs

Views oferecem uma leitura estável sobre tabelas que podem mudar. Procedures reúnem uma rotina com transação e tratamento de erro. O SQL Server Agent agenda a execução dessas rotinas e registra o resultado de cada passo, o que torna cargas e conciliações repetíveis e auditáveis.
